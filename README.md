# Умноград — школа информатики

Интерактивный тренажёр по информатике за 7 класс, удобный на компьютере и телефоне.

- 24 понятия и 120 вариантов заданий.
- При повторении меняются формулировки вопросов и ответов, а также порядок вариантов.
- Пять верных ответов подряд по одному понятию заполняют пять лучей звезды.
- Ошибка обнуляет лучи только текущего понятия; уже полученные звёзды сохраняются.
- Объяснения, книга подсказок и статистика обучения.
- Прогресс сохраняется в браузере на устройстве ученика. Синхронизации и общей базы результатов нет.

## Запуск

Файлы подготовлены для GitHub Pages: ветка `main`, каталог `/`. Публичная публикация пока не включена.

Весь тренажёр находится в `index.html`. Стили, JavaScript, задания и иллюстрация встроены в файл. Для локального запуска на компьютере можно открыть его в браузере. На телефоне используйте опубликованный сайт.

## Обновление

Замените `index.html` новой версией и отправьте изменения в ветку `main`. GitHub Pages опубликует обновление по прежнему адресу.

## Иллюстрация

Финтик — бобрёнок-изобретатель, Луми — светлячок, Бублик — ожившая булочка. Персонажи и круглая школа-мастерская разработаны для тренажёра. Иллюстрация создана с помощью генерации изображений и встроена в HTML.
