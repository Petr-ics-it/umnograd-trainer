# Люмен — академия знаний

Интерактивный тренажёр по информатике за 7 класс, удобный на компьютере и телефоне.

- При первом открытии — выбор светлой магии созидания или тёмной магии стихий.
- Сторона задаёт тему оформления; солнце/луна справа вверху переключают её без сброса ответов.
- Выбор темы сохраняется отдельно от учебного прогресса.
- 24 понятия и 120 вариантов заданий.
- При повторении меняются формулировки вопросов и ответов, а также порядок вариантов.
- Верный ответ добавляет один из пяти лучей звезды соответствующего понятия.
- Ошибка снимает один луч текущего понятия (не ниже нуля); уже полученные звёзды сохраняются.
- В полном курсе примерно половина вопросов относится к одному разделу (все его понятия), остальные случайно выбираются из других разделов. Порядок перемешивается, а после освоения раздела фокус переходит к другому. При отдельном запуске раздела вопросы остаются внутри него.
- До ответа видны только общий прогресс и счётчик собранных звёзд без подсказок о понятии или звезде. После ответа появляются название понятия, пояснение и карта 24 звёзд с анимацией луча. Полная карта также есть в достижениях.
- За четыре звезды раздела — большая наградная звезда и магический титул. Пройденные темы отмечены звездой, надписью «Завершено» и титулом; ранее завершённые разделы тоже получают титулы.
- Отдельный тест: 15 вопросов по разным понятиям из всех шести разделов, без подсказок и отметок правильности до завершения. Каждые три верных ответа дают один балл и луч звезды; максимум — 5 баллов.
- После завершения обучения предлагается пройти тест. Тест ограничен 30 минутами: обратный отсчёт продолжается при выходе со страницы и перезагрузке, паузы нет. По истечении времени тест автоматически завершается с показом результатов, в том числе при возвращении после закрытия страницы. Выбранные ответы учитываются, вопросы без ответа баллов не дают.
- В итогах теста показано время. Завершённые попытки на 5 баллов попадают в личные рекорды в разделах «Тест» и «Достижения». Старые результаты без учёта времени сохраняются, но в рекорды не входят.
- Объяснения, гримуар знаний и статистика обучения.
- 26 оригинальных векторных иллюстраций устройств и интерфейсов в пояснениях к 11 понятиям. Картинки появляются после ответа, увеличиваются по нажатию и чередуются в трёх подборках при повторении понятия.
- Прогресс сохраняется в браузере на устройстве ученика. Синхронизации и общей базы результатов нет.

## Запуск

Сайт: https://petr-ics-it.github.io/umnograd-trainer/

GitHub Pages публикует ветку `main`, каталог `/`. Для занятий не нужны вход в GitHub или установка приложений.

Весь тренажёр находится в `index.html`. Стили, JavaScript, задания и иллюстрация встроены в файл. Для локального запуска на компьютере можно открыть его в браузере. На телефоне используйте опубликованный сайт.

## Обновление

Замените `index.html` новой версией и отправьте изменения в ветку `main`. GitHub Pages опубликует обновление по прежнему адресу.

## Иллюстрация

Оригинальная магическая академия с каменными башнями, книгой и астролябией. Дополнительно экран выбора стороны содержит магию созидания и магию стихий. Иллюстрации созданы с помощью генерации изображений и встроена в HTML. Персонажи, логотипы и символика существующих произведений не используются.

## Проверка механики

`node tests/trainer.cjs` проверяет начисление и снятие лучей, случайное распределение по разделам, отсутствие подсказок до ответа, достижение звёзд и совместимость сохранённого прогресса.

`node tests/exam.cjs` проверяет состав теста, все варианты итоговой оценки, сохранение попытки, отсутствие обратной связи до завершения и независимость от учебного прогресса.
